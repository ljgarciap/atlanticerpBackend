**Nota de proceso:** la primera pasada de este escenario dio un falso "FAIL" — el entorno
dev.atlanticerp.ai tiene 5 productos calificando para "Por reordenar" (4 son fixtures viejos de
sesiones de QA anteriores, `QA-REC-001/002`, `QA-FLETE-A/B`). Un selector `.first()` en el script
de Playwright agarró la fila equivocada. Repetido apuntando a la fila del producto de prueba
específico → precarga exacta y correcta. Se documenta para que quede claro que no fue un hallazgo
real, sino un error del propio script de verificación.
