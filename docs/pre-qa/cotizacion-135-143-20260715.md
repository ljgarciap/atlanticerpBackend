de una sola vez.

## Nota metodológica — creación duplicada de cotización en `npm run dev` (recurrente, ver batch anterior)

Confirmado de nuevo en este batch: cada creación de cotización (tanto `/quotes` vacío como
`?fromSubClient=`/`?fromPipelineCard=`) dispara el efecto de auto-creación DOS VECES bajo
`React.StrictMode` (exclusivo de `npm run dev`, no ocurre en producción), dejando un draft
huérfano por cada una. Mitigación usada en los scripts de esta sesión: esperar a que la URL del
navegador se estabilice (dejar de cambiar) antes de tocar cualquier campo del formulario — si no,
el segundo ciclo de creación reemplaza el formulario a mitad de un `fill()` y produce fallos
intermitentes difíciles de diagnosticar (confundibles con bugs de producto). No reportar como bug.
